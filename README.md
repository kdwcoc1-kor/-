# 고흥귀농귀촌 앱 (1단계)

사단법인 고흥군귀농어귀촌협의회 공식 PWA — 홈 · 공지사항 · 행사 달력 · 협의회 소개(조직도)

## 배포 방법 (퍼머컬처ON과 동일)

1. GitHub에 새 저장소를 만들고 이 폴더의 파일 전체를 올립니다.
2. Netlify에서 "Import from Git" → 해당 저장소 선택 → 빌드 설정 없이 배포.
3. 배포된 https 주소를 휴대폰에서 열면 "홈 화면에 추가"로 앱처럼 설치됩니다.

## 내용 수정 방법 (사무국용)

`index.html` 파일을 열어 위쪽의 **"★ 데이터 수정 구역 ★"** 부분만 고치면 됩니다.

- **공지 추가**: `NOTICES` 목록에 `{ ... }` 블록 하나를 복사해 맨 위에 붙여넣고
  id 숫자를 겹치지 않게 바꿉니다. 분류(cat)는 `협의회 / 지원사업 / 총회·회의` 중 하나.
- **행사 추가**: `EVENTS` 목록에 날짜(`"2026-08-12"` 형식), 제목, 장소, 시간을 적습니다.
  `applyUrl`에 구글폼 주소를 넣으면 "참가 신청" 버튼이 자동으로 생깁니다.
- **연혁 수정**: `HISTORY` 목록.
- **조직도/인사말/연락처**: `index.html` 본문에서 `○○○` 표시를 실제 이름으로 바꿉니다.

수정 후 GitHub에 올리면 Netlify가 자동으로 재배포합니다.
이때 `sw.js` 맨 위의 버전 숫자(`goheung-app-v1`)를 v2, v3…으로 하나 올려 주세요.
